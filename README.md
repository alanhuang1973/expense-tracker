# 智匯記帳 ExpenseTracker PRO

一個精美、流暢、現代深色風格的個人收支記帳 Web App。採用純原生前端技術（HTML5 / CSS3 / ES6+ JavaScript）構建，無任何框架相依，所有資料均保存在使用者的瀏覽器 `localStorage` 中，注重隱私且離線可用。

🌐 **線上展示 (Live Demo)**：[https://alanhuang1973.github.io/expense-tracker/](https://alanhuang1973.github.io/expense-tracker/)

---

## ✨ 核心特色與功能

### 1. 快速記帳與智慧表單
- **收支類型切換**：支出 (Expense) / 收入 (Income) 快速切換。
- **直覺類別選擇**：
  - **支出類別**：餐飲、交通、娛樂、其他
  - **收入類別**：薪資、獎金、投資、其他
- **即時數額輸入**：支援金額驗證、貨幣符號、自定義日期（預設為今日）與備註欄位。
- **無縫編輯與安全刪除**：支援點擊列表項進行二次編輯與具備防誤觸確認的刪除機制。

### 2. 本月收支明細與導覽
- **月份切換導覽**：支援上個月、下個月、以及「回到本月」一鍵跳轉。
- **多維度統計卡片**：
  - 🔻 本月總支出
  - 🔺 本月總收入
  - 💎 本月淨結餘（自動根據盈餘/赤字切換提示與色彩）
  - 📝 本月總記帳筆數
- **表格呈現明細**：包含日期、收支類型徽章、類別彩籤、備註、金額（正負色彩區分）與操作按鈕。
- **即時篩選與即時搜尋**：可篩選「只看支出」或「只看收入」，並支援關鍵字即時過濾備註或類別。

### 3. 動態圓餅/環形圖分析 (Chart.js)
- 使用 **Chart.js** 繪製現代質感的甜甜圈圖（Doughnut Chart）。
- 支援「支出類別佔比」與「收入類別佔比」雙向切換。
- 深色主題 Tooltip，精確顯示各分類金額與百分比（%）。
- 附帶高可讀性的分類詳細佔比列表（依金額高低自動排序）。

### 4. CSV 資料匯出 (支援 Excel / UTF-8 BOM)
- 點擊頂部「匯出 CSV」即可一鍵匯出當前月份的所有記帳記錄。
- 特別加入 **UTF-8 BOM (`\uFEFF`)** 編碼，解決微軟 Excel 或 Numbers 開啟繁體中文時產生亂碼的問題。

### 5. 本地持久化與範例體驗
- **LocalStorage 儲存**：無需註冊、無伺服器後端，重整瀏覽器資料不遺失。
- **一鍵載入範例資料**：首次開啟自動載入精美示範記錄，亦可隨時點擊「範例資料」體驗。
- **清空資料功能**：提供確認對話方塊，方便重新開始。

### 6. 現代深色美學與全響應式設計 (RWD)
- **深色主題**：極致深邃背景（Obsidian / Deep Slate）、磨砂玻璃質感邊框與發光焦點。
- **圓角卡片**：18px 圓角柔和邊框設計，層次豐富。
- **自適應排版 (RWD)**：
  - **桌面版**：左側「新增記帳 + 分類圖表」與右側「月份導覽 + 明細表格」雙欄高效率作業。
  - **手機/平板版**：單欄流暢瀑布流，觸控按鈕經過 44px 人體工學優化。

## 🚀 如何運行

由於本專案為純靜態 Web 應用（Vanilla HTML/CSS/JS），無需安裝任何 npm 套件或建置工具：

### 方式一：直接用瀏覽器開啟
直接在檔案總管或 Finder 雙擊 `index.html` 即可在任一瀏覽器中開啟運行。

### 方式二：使用 Python 本地伺服器開啟
在終端機中切換至本專案目錄並執行：
```bash
# Python 3
python3 -m http.server 8080
```
接著在瀏覽器造訪 [http://localhost:8080](http://localhost:8080) 即可！
